# Tariffs

Drivers want to see pricing before they plug in. The tariffs API gives you the
current price for every connector in the location catalogue so you can display
it in your app. Tariffs are read-only: CPOs publish them via OCPI and the hub
exposes a simplified view for you.

## The price you see is the price you pay

Every price in this API is what **you** pay for the charge, not the CPO's raw
OCPI price:

- **VAT included.** Prices include VAT, which is never broken out.
- **Your agreement applied.** Each tariff is priced under your agreement with
  the CPO that publishes it:

| Your agreement | What you see |
|---|---|
| Public price | The CPO's price, VAT included |
| Discount | The CPO's price, VAT included, minus your discount, on every component |
| Fixed price | One `ENERGY` price per kWh, your fixed price, VAT included, in the CPO's currency |
| Wholesale | One `ENERGY` price per kWh (the CPO's wholesale price plus commission) in its currency, with no time windows, flat fee or other components |

It is the same price `POST /quotes` uses, under the CPO's same tariff ID, so you
can match it with the `tariff_id` of each connector in
[Locations](/ev-charging/distribution-partners/locations).
Prices carry up to 4 decimals per unit.

You only see the tariffs of CPOs you can buy from (see
[Which CPOs you see](/ev-charging/distribution-partners/locations#which-cpos-you-see));
for any other CPO, `GET /tariffs/{id}` answers `404 TARIFF_NOT_FOUND`.

## List tariffs

```http
GET /dp/v1/tariffs?limit=50&offset=0
Authorization: Bearer <your_dp_api_key>
X-Request-ID: a3d8f2c1-5b74-4e90-b6d1-9c0e2f7a8b34
```

| Parameter | Type | Default | Description |
|---|---|---|---|
| `limit` | integer | 50 | Page size (max 1000) |
| `offset` | integer | 0 | Number of records to skip |
| `updated_since` | ISO 8601 | — | Only tariffs whose price changed after this timestamp (see `last_updated`) |

**Response** (`HTTP 200`), on a public-price agreement with 16% VAT:

## Get a single tariff

```http
GET /dp/v1/tariffs/TARIFF-DEFAULT
Authorization: Bearer <your_dp_api_key>
X-Request-ID: b4e9a3d2-6c85-4f01-c7e2-0d1f3a8b9c45
```

**Response** (`HTTP 200`):

```json
{
  "data": {
    "id":           "TARIFF-DEFAULT",
    "currency":     "MXN",
    "elements": [
      {
        "components": [
          { "type": "ENERGY", "price": 7.54, "unit": "kWh" }
        ],
        "restrictions": null
      }
    ],
    "last_updated": "2026-04-29T08:00:00Z"
  }
}
```

## Tariff schema

| Field | Type | Description |
|---|---|---|
| `id` | string | The CPO's tariff identifier |
| `currency` | string | ISO 4217 currency code (e.g. `MXN`, `USD`); your agreement's currency on a wholesale agreement |
| `elements` | array | List of tariff elements (each with components and optional restrictions) |
| `last_updated` | ISO 8601 | When your price last changed: the latest of the CPO's last tariff update and the start of your current agreement terms |

## TariffElement schema

| Field | Type | Description |
|---|---|---|
| `components` | array | Price components that make up this element |
| `restrictions` | object &#124; null | When this element applies (see below); `null` means always applies |

## PriceComponent types

| Type | Unit | Description |
|---|---|---|
| `ENERGY` | kWh | Per-kilowatt-hour charge |
| `TIME` | hour | Per-hour charge for the duration of the session |
| `FLAT` | session | Fixed fee per session |
| `PARKING_TIME` | hour | Per-hour idle fee after charging stops |

Each component has three fields:

| Field | Type | Description |
|---|---|---|
| `type` | string | One of `ENERGY`, `TIME`, `FLAT`, `PARKING_TIME` |
| `price` | number | What you pay per unit, VAT included and your agreement applied |
| `unit` | string | Human-readable unit: `kWh`, `hour`, or `session` |

## Restrictions schema

Restrictions narrow when a tariff element applies. They are the CPO's own OCPI
restrictions, with the same names and units. Fields that are set must all hold;
a `null` field doesn't restrict. Times and dates are in the charge point's time zone.

| Field | Type | Description |
|---|---|---|
| `start_time` | string &#124; null | Start of the time window (`HH:MM`, 24-hour format) |
| `end_time` | string &#124; null | End of the time window (`HH:MM`); earlier than `start_time` means it runs past midnight |
| `day_of_week` | string[] &#124; null | Days when this element applies (e.g. `["MONDAY", "FRIDAY"]`) |
| `start_date` | string &#124; null | First day it applies (`YYYY-MM-DD`) |
| `end_date` | string &#124; null | Day it stops applying (`YYYY-MM-DD`, not included) |
| `min_kwh` | number &#124; null | Applies once this many kWh have been charged in the session |
| `max_kwh` | number &#124; null | Applies until this many kWh have been charged |
| `min_power` | number &#124; null | Applies while charging at this power (kW) or more |
| `max_power` | number &#124; null | Applies while charging below this power (kW) |
| `min_duration` | integer &#124; null | Applies once the session has lasted this many seconds |
| `max_duration` | integer &#124; null | Applies until the session has lasted this many seconds |

### Idle fees

An idle fee is a `PARKING_TIME` component, charged per hour while the car stays
plugged in without charging, usually limited by duration. For example, parking
free for the first 30 minutes of the session and 50 MXN/h after that:

```json
"elements": [
  {
    "components": [{ "type": "PARKING_TIME", "price": 0, "unit": "hour" }],
    "restrictions": { "max_duration": 1800, "min_duration": null }
  },
  {
    "components": [{ "type": "PARKING_TIME", "price": 50, "unit": "hour" }],
    "restrictions": { "min_duration": 1800, "max_duration": null }
  }
]
```

Durations count from the start of the session, not from when charging stopped.
(Other restriction fields omitted here; they are `null`.) Parking is not included
in `POST /quotes`, since how long a car stays can't be estimated; on a
public-price agreement the session's final `total_cost` includes it. On a
wholesale or fixed-price agreement you only see one price per kWh.

## Tariff locking

The tariff and your agreement terms in effect when a session starts determine
the price of that session. If a CPO updates a tariff or your agreement changes
while a session is in progress, the change does not affect the running session.
Only new sessions pick up the new price.

This means the price you see before your driver taps "Start charging" is the
price you will pay for that session.

## Keeping prices in sync

- **Webhook.** When a CPO changes a tariff, you receive `tariff.updated` with
  the `tariff_id`. Read your price with `GET /tariffs/{id}`.
- **Polling.** A new agreement with a CPO changes your price without any
  webhook. Poll `GET /tariffs?updated_since=...`: `last_updated` moves with
  your agreement too.

## Error responses

| HTTP | Error code | Meaning |
|---|---|---|
| `404` | `TARIFF_NOT_FOUND` | No tariff with this ID exists, or its CPO is not one you can buy from |
| `409` | `AMBIGUOUS_TARIFF` | The ID is published by more than one CPO |
